# Sky Post / Повітряна пошта

Казуальна 2D-вебгра для CrazyGames: куля керується лише жаром, а на кожній висоті вітер дме у свій бік.
Стек: Phaser 4.2.1, TypeScript 6, Vite 8.

## Команди

```bash
npm run dev          # http://localhost:5180, редактор рівнів на клавіші E
npm run build        # dist/ для подачі
npm run solve -- world1 world2 world3 --write   # перевірити рівні, записати пороги газу й маршрути підказки
```

## Структура

- `src/core/sim.ts` — детермінована фізика кулі з кроком 1/60. Одна й та сама для гри, розв'язувача й редактора.
- `src/core/solver.ts` — пошук у ширину по рішеннях «гріти чи ні» кожні 0.25 с. Дає мінімальну витрату газу (з неї поріг ★★ = оптимум × 1.3 + 0.8), маршрут з маркою для підказки і перевірку, що рівень проходиться.
- `src/levels/worldN.json` — рівні: шари вітру (`top`, `wind`, опційно `gust`/`period`), блоки, небезпеки (`move`), висхідні потоки, цілі по черзі, марка, `fuel`.
- `src/platform/platform.ts` — інтерфейс `Ads`: CrazyGames SDK v3 або заглушка. Під APK через Capacitor сюди додається реалізація для AdMob.
- `src/editor/` — редактор рівнів, лише в dev-збірці.

## Редактор (dev)

`E` — увімкнути редактор у поточному рівні. Інструменти: `1` блок (тягни), `2` ціль, `3` марка, `4` старт, `5` птах, `6` висхідний потік, `7` межа шару, `0` вибір (тягни — пересунути, Shift — змінити розмір).
Колесо змінює вітер шару, ширину цілі, радіус птаха або силу потоку. `M` — рух птаха, `G` — пориви шару, `F` — бак газу, `W`/`H` — розмір рівня.
`V` — розв'язати рівень у воркері: записує поріг газу й підказку. `S` — зберегти `worldN.json`. `[` `]` — перемкнути рівень, `N` — новий рівень, `P` — грати.
